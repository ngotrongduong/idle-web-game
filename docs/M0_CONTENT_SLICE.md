# M0 MVP content slice

This file records the first original data slice used to validate the M0 data pipeline.

## Counts
- 4 class families.
- 24 classes total: each family has 1 T1, 2 T2 and 3 T3 classes.
- 4 dungeons.
- 12 enemy families: 3 per dungeon.
- 32 craftable equipment items.
- 15 materials.

## Originality rules
- Names, descriptions and data in this slice are original project content.
- Reference-game research informs system structure only.
- Do not copy reference-game class names, item names, lore, art, UI, exact data tables or formulas.

## Families
- Vanguard: tank / physical frontline.
- Ranger: fast physical damage.
- Arcanist: magic damage.
- Warden: support / healing.

## Dungeon progression
1. Bamboo Grove — recommended level 1.
2. Misty Riverbank — recommended level 10.
3. Sunken Shrine — recommended level 20.
4. Ember Ridge — recommended level 30.

The values are seed data for simulation, not final balance. All balance changes should be made in config and rechecked with `tools/sim`.
